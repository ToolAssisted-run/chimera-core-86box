# AGENTS.md - 86Box core for Chimera

This repository builds 86Box, the PC emulator, as a sandboxed guest for
Chimera (https://github.com/ToolAssisted-run/chimera), a frontend for
tool-assisted speedruns. It produces one file, `86box.chimeraCore`.
`docs/BUILDING.md` has the detail behind every command here; `docs/PLAN.md`
is the design log and ends with where the work stands.

## Layout

- `extern/86box/` - upstream 86Box, a submodule pinned at the v6.0 release.
  Never commit in it.
- `patches/` - numbered patches against `extern/86box`, each behind
  `CHIMERA_CORE`. `waterbox/apply-patches.sh` applies the whole series.
- `meson.build` - both builds: native (`build/meson-native`: `run-native`,
  `run-wbx`, `list-machines`) and guest (`build/meson-guest`: `core.wbx`).
- `waterbox/sources.py` - the upstream files compiled, read from upstream's
  CMakeLists.txt files, less what reaches the host.
- `waterbox/chimera-plat.c` - 86Box's platform layer: files, memory, time,
  threads, messages. `cinterface.c` - the guest interface and the
  configuration composed from the settings. `chimera-input.c` - the
  controller. `chimera-audio.c` - the sound streams mixed to 48000 Hz.
- `waterbox/compat/` - stand-in headers for libpng, libsndfile and zlib.
- `waterbox/gate-harness.h`, `run-native.c`, `run-wbx.c` - the test runners.
- `waterbox/run-gate.sh` - the gate. `waterbox/tests/` - the window test and
  its helpers, the movie writer.
- `waterbox/waterbox.config` - GENERATED by `tools/gen-config.py` from
  86Box's tables (`list-machines`). Do not edit it by hand.
- `waterbox/languages/` - the texts a person reads, 26 languages.
- `tests/free-bios/` - builds the free Xi 8088 BIOS. `tests/boot-probe/` -
  the gate's boot floppy. `waterbox/xtide-bios/` - builds the XTIDE Universal
  BIOS (GPL) for 86Box's two XT-IDE cards from source; the core carries
  those two ROMs (`embed.py` writes them into the build, SHA-1 checked). `tests/hdd-dos/` - makes a FreeDOS hard disk.
  `tests/cd/` - makes the test CD (a data track and an audio track).
  `tests/dos-disk/` - makes FreeDOS floppies and hard disks with a test's
  files. `tests/keys.py` - typed text and keys as the runners' options;
  `tests/games/` - the input of the game tests.
- `tools/pin-roms.py` - the SHA-1 of each declared ROM file, from 86Box's
  ROM set, into `tools/rom-sha1.json` (which `gen-config.py` reads).

## Commands, in order

```sh
git submodule update --init
export XUB_SRC=$PWD/build/src/xub-r638  # fetched as waterbox/xtide-bios/xub.ref says; the builds need it
CHIMERA=/path/to/chimera          # built: chimera-run, the window, test-packages
MB=$CHIMERA/extern/chimera-common-minibox
meson setup build/meson-native -Dminibox_dir=$MB -Dxub_src=$XUB_SRC && ninja -C build/meson-native -j4
sh waterbox/setup-guest.sh -m $MB && ninja -C build/meson-guest -j4 core.wbx
sh waterbox/build-package.sh -m $MB                     # -> build/Cores/86box.chimeraCore
git clone https://github.com/skiselev/8088_bios.git build/src/8088_bios   # then check out tests/free-bios/8088_bios.ref
CHIMERA_ROOT=$CHIMERA FREE_BIOS_SRC=build/src/8088_bios sh waterbox/run-gate.sh
```

The gate must end with `0 failed`. Read the skipped count: without
`FREE_BIOS_SRC` no machine runs. `FREEDOS_FLOPPY` adds the FreeDOS legs
(from its floppy, and from a hard disk through the carried XTIDE Universal
BIOS); `PCBOX_ROMS` (the ROM set of 86Box, v6.0) adds IBM's machines with
IBM's ROMs and the 486 and Pentium boards, and `PCBOX_KROZ` and
`PCBOX_DOOM` two real games (docs/BUILDING.md); the window leg
needs the window's Qt on `LD_LIBRARY_PATH`.

## Rules of this repository

- Never commit inside `extern/86box`. A change to 86Box is a numbered patch,
  behind `#ifdef CHIMERA_CORE`, and `sh waterbox/apply-patches.sh` must say
  `already applied: all <n> patches` on your tree.
- Determinism is the product: nothing may read the host's time, randomness,
  files or environment in either build (the native build may only for a
  test's negative control, through an environment variable). A new thread
  in 86Box is refused at load by name; make the device run in place instead.
- A new gate leg is broken on purpose once and seen to fail; say so in the
  commit. Assert the machine is alive before comparing anything.
- The recompiler's code must be the same length wherever the host puts
  things (patch 0008): a block ends when its host code fills a buffer, so
  code of another length is another machine. A new emitter path that picks
  a short form by address breaks native == sandbox.
- Regenerate `waterbox/waterbox.config` with `tools/gen-config.py` after
  changing the machines, the controller or the generator.
- Every text a person reads is a key of `waterbox/languages/en.json`, and
  every language table has every key.
- Names are never translated or bent, in any table, English too (the
  owner, 2026-10-31): 86Box, IBM, the 8088, Chimera... are written as they
  are, with no ending glued or hung on them ("86Box's", "IBM:n", "IBM-a");
  say it with a common noun beside the name. A new name goes into
  `tools/check-names.py`'s list; the gate runs it on all 26 tables.
- Never commit a ROM, BIOS, disk image or game; never look for them on the
  machine. The owner supplies them. The one ROM the core carries, the XTIDE
  Universal BIOS (the owner, 2026-10-31), is built from its pinned source,
  never committed as a binary.
- Scripts under `waterbox/` and `tests/` are POSIX `sh` (the window test is
  bash). Prose is plain ASCII. Commits: `type(86box): what is now true`, the
  body says what ran, with the numbers.
